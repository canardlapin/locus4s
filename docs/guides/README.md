# Guides

These guides combine the core abstractions into complete tasks.

- [Fields and aggregation](fields-and-aggregation.md) gathers, pulls back, and
  pushes values while leaving storage open to downstream implementations.
- [Persistence and restoration](persistence-and-restoration.md) records and
  reconstructs domains and structures through validated neutral values.
- [An imaging-shaped workflow](imaging-shaped-workflow.md) builds compact masked
  data, a parcellation, and searchlights without adding imaging policy to the
  foundation.

Read the [Concepts](../concepts/README.md) section first if owner types,
position domains, or map direction are unfamiliar.
