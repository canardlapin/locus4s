# locus4s 0.1.0 release notes

locus4s 0.1.0 is the first immutable release of the identity-safe finite-domain
algebra for Scala 3 on the JVM and Scala.js.

It establishes:

- generative finite-domain owners and zero-cost typed indices;
- canonical regions, selections, total/partial/certified maps, and sparse
  relations with explicit owner alignment;
- neutral checked persistence records;
- representation-neutral fields and deterministic aggregation; and
- reusable cross-platform laws plus executable documentation.

Before freezing this baseline, relation constructors and `converse` were made
total at the CSR row-offset limit. They return
`Left(RelationError.RowOffsetCountOverflow)` before attempting an impossible
`Int.MaxValue + 1` allocation.

The stable compatibility policy is early-semver: compatible changes remain on
`0.1.x`; breaking public or semantic-contract changes require `0.2.0`.
